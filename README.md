 About my website
I made a website for Tshwane Youth Comunity Center. The idea is people can read about what we do and contact us if they want to volunteer or donate. I used HTML, CSS and JavaScript.

 Feedback from Part 2 and what I fixed
My lecturer said a few things I must fix from Part 2 so I fixed them.

1. Navigation - On phone the menu was not working, so I added a hamburger menu with JS.
2. Images - Images were big and had no alt text. I compressed them and added alt text.
3. SEO - I didn't have titles and descriptions. Now each page has its own title and description.
4. Forms - Forms had no checks. I added required and some JS validation.

 JavaScript for Part 3
For Part 3 I added:
- FAQ accordion on About page using jQuery
 I put a marker for our location
- Lightbox for gallery so images open bigger
- Search bar on services page that filters as you type
- JS to show the year in footer

SEO
What I did for SEO:
- Put keywords in my headings like volunteer, donation etc
- Added good titles and descriptions for each page
- Renamed images properly and added alt text
- Made site work on mobile
- Added internal links from menu and buttons
- Added address and map for local SEO

Forms
I have two forms:

enquiry.html - for enquiries about volunteering/sponsorship. It asks for name, email, phone, type of enquiry and message. After submit it shows a message like "Thank you".

contact.html - for general contact. Name, email, subject, message.

For validation I used HTML required and type="email". I also used JavaScript to check if fields are empty and show error messages in red. I used preventDefault so the page does not refresh.

 How to run
Just download or clone and open index.html, or use Live Server in VS Code.
